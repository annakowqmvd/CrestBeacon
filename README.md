# CrestBeacon

CrestBeacon is a real-time, geo-spatial analysis platform that aggregates multi-sensor data and triggers alerts via a scalable gateway.

CrestBeacon is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/CrestBeacon.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

CrestBeacon is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
